# Estadistica

#  Media Aritmética y Desviación Estándar Interactiva

Aplicación web interactiva desarrollada como material de apoyo para la enseñanza de **Estadística Descriptiva**, enfocada en los conceptos de **media aritmética** y **desviación estándar**.

La aplicación permite al usuario comprender estos conceptos mediante explicaciones teóricas, ejemplos interactivos, gráficas dinámicas y un cuestionario de autoevaluación.

##  Características

-  Explicación teórica de la media aritmética.
-  Explicación teórica de la desviación estándar.
-  Gráfica interactiva donde es posible mover los datos y observar cómo cambian las medidas estadísticas en tiempo real.
-  Desarrollo paso a paso del cálculo de la media y la desviación estándar.
-  Ejemplo con datos agrupados que permite modificar frecuencias y actualizar automáticamente:
  - Tabla de distribución.
  - Gráfica de barras.
  - Media aritmética.
  - Desviación estándar.
  - Evaluación de simetría de la distribución.
-  Cuestionario interactivo para reforzar el aprendizaje.
